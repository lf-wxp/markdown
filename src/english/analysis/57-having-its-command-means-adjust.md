# Having at its command the means to adjust action in an infinite number of ways, according to the exact situation at hand, science travels rapidly and gets things done

> Having at its command the means to adjust action in an infinite number of ways, according to the exact situation at hand, science travels rapidly and gets things done

下面分析这个句子的结构。原句为：

> *Having at its command the means to adjust action in an infinite number of ways, according to the exact situation at hand, science travels rapidly and gets things done.*

这是一个书面语中常见的**复杂句**，主句在前，前面带有一个表示“原因”或“伴随状态”的**分词短语**（作状语）。我们分层解析。

## 1. 整体结构

| 层次 | 成分 | 说明 |
|------|------|------|
| **状语（分词短语）** | `Having at its command the means to adjust action in an infinite number of ways, according to the exact situation at hand` | 表示科学之所以能“快速行动并做成事情”的原因或方式 |
| **主句** | `science travels rapidly and gets things done` | 句子的核心主语和谓语 |

## 2. 状语（分词短语）内部结构

分词短语的核心是 **Having + 宾语 + 宾语补足语/状语**。这里用了倒装：`at its command` 被提到了宾语 `the means` 之前。

### 正常语序还原：
`Having the means to adjust action in an infinite number of ways at its command, according to the exact situation at hand`

### 逐层分析：

| 成分 | 对应部分 | 说明 |
|------|----------|------|
| **现在分词** | `Having` | 主动意义，逻辑主语是 `science` |
| **状语（地点/状态）** | `at its command` | 介词短语，`its` 指 `science`，“在科学的掌握之中” |
| **宾语** | `the means` | 名词，“手段/方法” |
| **定语（不定式）** | `to adjust action in an infinite number of ways` | 修饰 `means`，说明是什么样的方法 |
| └── 不定式核心 | `to adjust` | |
| └── 宾语 | `action` | |
| └── 状语 | `in an infinite number of ways` | 介词短语，修饰 `adjust` |
| **插入状语** | `, according to the exact situation at hand,` | 介词短语，修饰 `adjust action`，表示“根据手头的具体情况” |

所以整个分词短语的意思是：“由于科学拥有能根据手头具体情况以无数种方式调整行动的方法”。

## 3. 主句内部结构

`science travels rapidly and gets things done`

| 成分 | 对应部分 | 说明 |
|------|----------|------|
| **主语** | `science` | 名词 |
| **第一个谓语** | `travels rapidly` | 不及物动词 + 副词 |
| **并列连词** | `and` | 连接两个谓语 |
| **第二个谓语** | `gets things done` | 及物动词 + 宾语 + 过去分词作宾补 |

`gets things done` 是 **get + 宾语 + 过去分词** 结构，表示“使事情被完成”。

## 4. 全句结构树状图

```
Having at its command the means to adjust action in an infinite number of ways, according to the exact situation at hand, science travels rapidly and gets things done.
│
├─ 分词短语 (状语)
│   ├─ 分词: Having
│   ├─ 介词短语 (提前): at its command
│   ├─ 宾语: the means
│   │   └─ 定语: to adjust action in an infinite number of ways
│   │       ├─ to adjust
│   │       ├─ 宾语: action
│   │       └─ 状语: in an infinite number of ways
│   └─ 插入状语: according to the exact situation at hand (修饰 adjust)
│
└─ 主句
    ├─ 主语: science
    └─ 并列谓语:
        ├─ 谓语1: travels rapidly
        └─ 谓语2: gets things done
            ├─ 谓语动词: gets
            ├─ 宾语: things
            └─ 宾语补足语: done (过去分词)
```

## 5. 句意理解

这个句子用生动的语言描述**科学的特点**：科学因为能够根据具体情况灵活调整方法，所以推进迅速且富有成效。

**参考翻译：**  
“科学掌握了能根据手头具体情况以无数种方式调整行动的手段，因此它进展迅速，并能办成事情。”

## 6. 语法点总结

| 语法点 | 说明 |
|--------|------|
| **现在分词短语作状语** | 表示原因或伴随，逻辑主语与主句主语一致（`science`） |
| **倒装结构** | `Having at its command the means` 将地点状语提前，使宾语后置，避免头重脚轻 |
| **不定式作定语** | `to adjust action...` 修饰 `the means` |
| **插入成分** | `according to ...` 用逗号隔开，提供附加信息 |
| **get + 宾语 + 过去分词** | `gets things done` 表示使役，“使……完成” |
| **并列谓语** | `travels ... and gets ...` 两个动作连续发生 |
