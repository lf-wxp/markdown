# be cracked up to be

> Depth isn’t all it’s cracked up to be

这是一个非常地道的英语习语，其句子结构也很有意思。

## 1. 整体句型

这是一个 **“主系表” 句型**，带有一个**定语从句**。

## 2. 成分分析

*   **主语：** `Depth` （深度）
*   **系动词：** `isn't` （是 `is not` 的缩写）
*   **表语：** `all` （核心表语，在这里是名词，意为“全部”、“人们所说的那样”）
*   **定语从句：** `(that) it's cracked up to be` （修饰前面的 `all`）
    *   这个定语从句可以进一步分解：
        *   `(that)`： 关系代词，引导定语从句并指代 `all`，在从句中作 `to be` 的补足语，通常被省略。
        *   `it's`： 是 `it is` 的缩写。`it` 是主语，指代主句的主语 `Depth`。
        *   `cracked up`： 过去分词短语，与 `is` 构成被动语态，`crack up` 是一个固定短语，意为“高度赞扬”、“吹捧”。
        *   `to be`： 不定式，与前面的 `cracked up` 构成固定搭配 `be cracked up to be`（被吹捧成…的样子）。

## 3. 句子主干与句意

*   **主干：** **Depth isn't all.**
    （深度并非一切。/ 深度并不像说的那么神。）

*   **完整句意（直译）：** “深度并不完全是它被吹捧成的那个样子。”
*   **地道意译：** “深度这东西，其实没有传说中那么好。” 或 “深度是名过其实了。”

## 4. 核心结构：be (not) all (that) sb/sth is cracked up to be

这是一个非常常用的英语习语模板，用于表达某人或某事物“并不像大家说的那么好”、“名不副实”。

*   The new restaurant **isn't all it's cracked up to be**.
    （那家新餐厅并没有传说中那么好。）
*   He's a good player, but he **isn't all he's cracked up to be**.
    （他是个好球员，但不像媒体吹捧的那么神。）

## 5. 总结图表

| 句子成分 | 对应部分 | 词性/功能说明 |
| :--- | :--- | :--- |
| **主语** | `Depth` | 名词 |
| **系动词** | `isn't` (`is not`) | 系动词（否定） |
| **表语** | `all` | 名词 |
| **定语从句** | `(that) it's cracked up to be` | 修饰 `all` |
| └── **关系代词** | `(that)` | 引导定语从句，作补语（可省略） |
| └── **主语** | `it` | 指代主句主语 `Depth` |
| └── **谓语** | `'s cracked up` | 被动语态（被赞扬/吹捧） |
| └── **补足语** | `to be` | 不定式，与 `cracked up` 搭配 |
