# You are not choosing them anymore than i am choosing them

> You are not choosing them anymore than i am choosing them 

这是一个非常典型的**否定比较结构**，使用了固定搭配 **“not ... any more than ...”**。整个句子由两个并列的（比较）分句构成，但严格来说，第二个分句是**比较状语从句**。

你原句里的 `anymore` 通常应写作 **`any more`**（分开写），但在现代英语中，尤其是在非正式语境下，“any more than” 作为固定词组也常被连写。我们按标准结构来分析：

**原句（标准化拼写）：** *You are not choosing them any more than I am choosing them.*

## 1. 整体结构与逻辑含义

这是一个**否定比较句**，核心公式为：**A is not ... any more than B is ...**

- **逻辑含义**：A 和 B 在程度上是相等的，且都是否定含义。
- **通俗理解**：`not ... any more than` 相当于 `not ... just as ... not`（A 不……，正如 B 也不……一样）。

**本句逻辑**：“你（现在）没有在选他们，**正如**我（现在）也没有在选他们一样。” → 即 **“你和我都没有在选择他们。”**

## 2. 成分分析

**第一分句（主句）：** `You are not choosing them`

这是一个**现在进行时**的否定陈述句。

| 成分 | 对应部分 | 说明 |
| :--- | :--- | :--- |
| **主语** | `You` | 代词 |
| **谓语（否定）** | `are not choosing` | 现在进行时，否定形式 |
| **宾语** | `them` | 代词宾格 |

**连接/比较部分：** `any more than`

这是一个**复合连词**，用于连接比较状语从句，意为“比……更”、“正如……不……”。这里的 `any` 用来加强语气，修饰 `more`。

**第二分句（比较状语从句）：** `I am choosing them`

这是从属的比较分句，用于与主句进行类比。

| 成分 | 对应部分 | 说明 |
| :--- | :--- | :--- |
| **（从属）连词** | `(any more) than` | 引导比较状语从句 |
| **主语** | `I` | 代词 |
| **谓语** | `am choosing` | 现在进行时（肯定形式） |
| **宾语** | `them` | 代词宾格 |

> **注意**：虽然从句是肯定形式（`am choosing`），但由于主句有否定词 `not`，整个结构传达的是**双重否定下的等量比较**——即主句和从句的动作都**没有发生**。

## 3. 结构树状图

```
You are not choosing them any more than I am choosing them.
│
├─ 主句 (Main Clause)
│   ├─ 主语: You
│   ├─ 谓语: are not choosing
│   └─ 宾语: them
│
└─ 比较状语从句 (Comparative Clause)
    ├─ 连词: any more than
    └─ 从句内部:
        ├─ 主语: I
        ├─ 谓语: am choosing
        └─ 宾语: them
```

## 4. 省略与变形

在实际使用中，为了避免重复，从句末尾的 `them` 有时会省略，变成：

> *You are not choosing them any more than I am.*  
> （你没有在选择他们，正如我也没有一样。）

## 5. 句意与翻译

- **直译**：“你现在并不比我现在更是在选择他们。”
- **地道意译**：“你没有在选他们，同样，我也没有在选他们。” 或 “我和你都没在选他们。”

## 6. 核心语法点总结

| 语法点 | 说明 |
| :--- | :--- |
| **比较结构** | `not ... any more than ...` 表示 A 和 B 一样都不 |
| **时态呼应** | 主句和从句都用了现在进行时（`are/am choosing`），表示当前正在进行的动作 |
| **否定范围** | 否定词 `not` 不仅否定主句，也通过 `any more than` 将否定意义辐射到从句 |
| **从句省略** | 从句末尾的宾语 `them` 在口语中常可省略 |
